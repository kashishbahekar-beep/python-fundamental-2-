# Python Fundamentals (Part 2)

Practice assignments and exercises focusing on conditional logic, loops, and functions in Python.

## Topics Covered
- **Conditional Statements:** `if`, `elif`, `else`, nested conditionals, and `match-case`
- **Loops & Iteration:** `for` loops, `range()` function, and `break` & `continue` statements
- **Functions:** Defining functions, types of functions, and `lambda` functions
- **Practice Programs:** Odd or Even, Multiplication Table of N, Vowel Count, Sum of N numbers, and Factorial of N

## Tech Stack
- **Language:** Python
- **Editor:** VS Code
